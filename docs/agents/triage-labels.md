# Triage-Labels

Die Skills sprechen in fünf festen Triage-Rollen. Diese Datei ordnet den Rollen die tatsächlichen Label-Zeichenketten im Issue-Tracker dieses Repos zu.

| Rolle (Standard-Label) | Label in unserem Tracker | Bedeutung                                         |
| ---------------------- | ------------------------ | ------------------------------------------------- |
| `needs-triage`         | `needs-triage`           | Muss vom Entwickler bewertet werden               |
| `needs-info`           | `needs-info`             | Wartet auf weitere Infos vom Melder               |
| `ready-for-agent`      | `ready-for-agent`        | Vollständig beschrieben, bereit für einen Agenten |
| `ready-for-human`      | `ready-for-human`        | Muss von einem Menschen umgesetzt werden          |
| `wontfix`              | `wontfix`                | Wird nicht umgesetzt                              |

Erwähnt ein Skill eine Rolle (z. B. „setze das Triage-Label für Agenten-bereit“), verwende die passende Zeichenkette aus dieser Tabelle.

Passe die Spalte „Label in unserem Tracker“ an das Vokabular an, das du tatsächlich nutzt.
